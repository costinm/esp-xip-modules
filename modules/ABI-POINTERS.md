# Pointers in the table ABI

Generated by `scripts/abi-pointers.py` from `include/xip.h`. Direction: a call that crosses the module/host boundary
must not depend on shared memory or pointers (binder model: a CBOR record or a pool packet, or a pointer-free
fixed struct). Every row below breaks that and is a candidate to change. Kinds: `struct*` = pointer to a C struct
(layout and any pointer inside it become ABI); `buffer` = caller bytes (`uint8_t *`, `char *`), should become a packet or
a record; `out-pointer` = host returns a pointer into its own memory; `scalar-out` = small out parameter, returnable as a
pointer-free result record.
